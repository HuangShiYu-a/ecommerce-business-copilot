# UI Workbench E0 — 结构草图（V0.1）

> 文档性质：UI 结构草图（非最终设计；供评审后演进为 E1 详细设计）  
> 版本：**V0.1**  
> 技术栈：NiceGUI（纯 Python 全栈，底层 FastAPI/uvicorn；Spec-1 AR-18 流式展示）  
> 数据来源：`run_agent()`（copilot/agent/orchestrator.py）、`runtime.session`、LangGraph PostgresSaver

---

## 1. 目标范围（V1）

对照 GPT 网页版，只做三块 + 一块必选上下文：

| 区块 | 内容 | 数据来源 |
|------|------|----------|
| 左栏 | 新建对话 + 会话历史列表 | `runtime.session` |
| 主区 | 消息气泡流（用户/助手） | checkpoint conversation |
| 底部 | 输入框 + 发送 | `run_agent()` |
| 上下文 | 角色（客服/运营）+ 门店（1/2） | `session.role / store_id` |

**非目标（V1）**：登录鉴权、流式打字机、历史搜索、会话重命名、文件上传、多模型选择。

## 2. 布局（GPT 网页版风格）

```
┌──────────────────────────────────────────────────────────────────────┐
│  ┌────────────────┐  ┌─────────────────────────────────────────────┐ │
│  │  左栏 (260px)   │  │  顶栏：标题「E-commerce Copilot」            │ │
│  │                │  │  [角色 ▾] [门店 ▾]        [＋ 新建对话]       │ │
│  │  ┌──────────┐  │  ├─────────────────────────────────────────────┤ │
│  │  │ ＋ 新建    │  │  │  主区消息流（自动滚动到底）                  │ │
│  │  │   对话     │  │  │                                            │ │
│  │  └──────────┘  │  │  ┌──────────────────────────┐              │ │
│  │  会话历史      │  │  │ 用户 │  SKU_01_...缺货风险 │              │ │
│  │  · 今日        │  │  └──────────────────────────┘              │ │
│  │    - 会话 A    │  │  ┌──────────────────────────┐              │ │
│  │    - 会话 B ●  │  │  │ 助手 │ 缺货风险评估：HIGH  │              │ │
│  │  · 更早        │  │  │      （可用 12 件，约 6 天…）│              │ │
│  │    - 会话 C    │  │  └──────────────────────────┘              │ │
│  │                │  ├─────────────────────────────────────────────┤ │
│  │                │  │  底部： [请输入问题…            ]  [发送 ⏎]    │ │
│  └────────────────┘  └─────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

- **左栏**：窄侧边，会话列表按 `updated_at` 倒序；当前会话高亮。
- **主区**：气泡流，用户靠右 / 助手靠左；空会话显示引导文案（建议问题）。
- **底部**：固定输入栏；发送后清空、追加用户气泡、显示助手回复。
- **顶栏**：角色/门店下拉（全局会话上下文）；「新建对话」也可放左栏按钮。

## 3. 组件清单（NiceGUI 映射）

| 组件 | NiceGUI 元素 | 说明 |
|------|-------------|------|
| 页面骨架 | `ui.header` / `ui.left_drawer` / `ui.column` / `ui.footer` | 三栏布局 |
| 会话列表 | `ui.list` + `ui.item`（on_click 切换） | 读 `runtime.session` |
| 新建对话 | `ui.button("＋ 新建对话")` | 生成新 `session_id` + 空主区 |
| 角色选择 | `ui.select(role)` | 客服 / 运营 |
| 门店选择 | `ui.select(store_id)` | 1 / 2 |
| 消息气泡 | 动态 `ui.chat_message` 或 `ui.label` + CSS | 用户/助手样式区分 |
| 输入框 | `ui.input`（enter 触发）+ `ui.button("发送")` | 发送 → `run_agent()` |
| 引导文案 | `ui.column`（空会话时） | 建议问题（8 个意图各一条）|

## 4. 数据流（一次对话轮）

```
用户点发送
  → api.py: 组装 session{user_id, role, store_id, session_id}
  → run_agent(graph, thread_id=session_id, session, message)
  → 返回 response{message, status, result, needs_user_input...}
  → 前端：追加助手气泡（response.message）；status 变化提示
```

- **thread_id = session_id**（1:1，Spec-2 §2）。
- **首轮**传完整 session；**续轮**只传 message（其余走 checkpointer 持久化）——`run_agent` 已封装。
- **会话历史刷新**：切会话时读该 thread 的 `conversation`（`graph.get_state`），渲染气泡流。

## 5. 状态与边界

| 场景 | 处理 |
|------|------|
| 空消息发送 | 禁用发送按钮 / 忽略 |
| 等待用户输入（WAITING_USER_INPUT） | 正常显示回复，用户继续发消息即续答 |
| 无权限 / 跨店 FORBIDDEN | 回复消息已含「无权访问」，正常展示 |
| 会话切换 | 主区清空 + 加载目标会话消息 |
| 新建对话 | 立即切到空会话（不落库，首次发送才 create_session）|
| 后端异常（LLM/DB 挂） | 气泡显示错误，不崩溃 |
